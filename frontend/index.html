About This Project

Diabetes is one of the fastest growing chronic diseases. Early prediction helps patients take preventive action before complications occur. This project uses Machine Learning to estimate diabetes risk using medical information like Age, BMI, Blood Pressure, Glucose, Pregnancy, Heart Disease and Family History.
