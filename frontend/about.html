About Diabetes Prediction System

Learn about diabetes, our project and the technology used.

🩺 What is Diabetes?

Diabetes is a chronic disease in which the blood glucose level becomes higher than normal. If it is not detected early, it can affect the heart, kidneys, eyes and nerves.

⚠ Symptoms

  • Frequent Urination
  • Excessive Thirst
  • Fatigue
  • Blurred Vision
  • Slow Healing of Wounds
  • Sudden Weight Loss

🥗 Prevention

  • Maintain Healthy Weight
  • Exercise Daily
  • Eat Balanced Diet
  • Reduce Sugar Intake
  • Regular Health Checkups

🤖 Machine Learning Model

This project uses a trained Random Forest Machine Learning model to predict diabetes risk using health parameters such as glucose level, BMI, blood pressure, pregnancy, age, heart disease and family history.

💻 Technologies Used

  • Python
  • Flask
  • HTML5
  • CSS3
  • JavaScript
  • Scikit-Learn
  • Random Forest Algorithm

📊 Model Information

The prediction is generated using a Machine Learning model trained on diabetes-related medical data. The result provides an estimated risk level and should be considered as supportive information rather than a medical diagnosis.

⚕ Disclaimer

This application is developed for educational purposes. It does not replace professional medical advice. Always consult a qualified healthcare professional for diagnosis and treatment.
